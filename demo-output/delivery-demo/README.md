# 周报交付流程演示

这是一份已有演示稿的重新排版，不是新创作或已发布文章。

## 查看

- `out/sheet.html`：发布工作台，包含元信息、复制按钮、正文和三档封面。
- `out/article.html`：独立文章预览，使用 growth 成长橙主题。
- `article.md`：原样复制的 Markdown 源稿，未改写。
- `out/check-report.json`：实际发布前提示检查结果。
- `out/lint-report.json`：实际写作来源提示结果。

## 本次实际运行

1. 以新输出目录运行 md2wx.py，不预先创建 out，验证自动建目录。
2. 复用 `../weekly-report/` 中三档封面和 `fig-reader-chain.png`，复制到最终工作台同目录。
3. 重新运行 md2wx.py --sheet，生成最终预览、正文片段和工作台。
4. 运行 check.py --strict --json 与 lint.py --json，并保存实际报告。
