- designs/：为什么这样设计、能力边界。
- plans/：实施步骤和执行状态。
- reports/：真实检查证据、未验证项和交付结果。

文件采用`YYYY-MM-DD-主题.md`命名。旧历史记录按所属skill归类，只更新可点击入口和当前命令位置，不把旧时间戳或旧验收升级成新结论。
