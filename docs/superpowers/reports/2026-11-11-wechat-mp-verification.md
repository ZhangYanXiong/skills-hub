## 问题关闭情况

| 范围 | 已修复及验证 |
| --- | --- |
| 交付闸门 | 快速开始双 `--strict`；最终生成后再执行 lint/check；完整发布就绪验收加 `--publish`，普通局部排版不强制封面或快照 |
| 产物完整性 | schema 2 逐项记录完整 SHA256；HTML、正文、工作台任一声明文件缺失/篡改会阻断；坏清单结构不能静默通过 |
| 有效渲染参数 | 实际主题、标题、作者及覆盖状态、输出选项参与指纹；合法主题覆盖不会误判；不同标题/作者不再共用不可变快照 |
| 本地资产 | 图片/封面字节参与指纹；清单资产索引与实际 HTML 引用核对，清空索引不能绕过快照校验 |
| 完整快照 | 保存源稿、产物、本地图片和封面；重复快照不覆盖历史；回退先完整校验，再恢复源稿及资产 |
| 写入安全 | 源稿、固定 build.json、其他产物、资产的规范路径、符号链接、硬链接身份碰撞在写入前拒绝；错误目录或快照根不先覆盖旧 HTML |
| 清理与回退 | 生成和回退共用写入检查；清理排除新写入文件的实际别名；父目录别名不再让刚恢复的源稿被删除；大小写改名不再删除新产物 |
| 数值 | 保留正负号、完整复合单位；等价小数及常见中文数量规范化；“千万不要”等副词不再当成无出处数量 |
| 素材卡 | 明确传入但解析为零张必须阻断；未知/存疑编号继续检查；重排表头空出处不回退到备注；类型矛盾和无出处 F 卡不能冒充已核验数字 |
| 大纲 | 加粗标题后读取主论点；短判断句不一律判死，覆盖“缓存缩短耗时。”；句尾标点套话、中文支撑编号均有回归 |
| 代码围栏 | 渲染、lint、check 共用符号及闭合长度规则；覆盖嵌套围栏和紧接段落的额外语言信息 |
| CLI 健壮性 | `--publish` 缺 `--out` 明确退出 2；非法历史清单退出 1且无 Traceback，同时继续列出正常历史 |
| 文档边界 | 保留默认署名与可选发布就绪验收；明确三档尺寸是项目规格，PNG 头检查不等于完整解码或微信验收 |
