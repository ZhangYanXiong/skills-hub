# wechat-mp 新版问题闭环修复

用户已要求修复评估发现的全部问题，并在同一轮主动检查、修复复核新增发现。

## 范围与约束

保持 Python 3.9+ 标准库及已有 CLI；不安装、不修改原演示稿、不操作微信、不提交。检查与回退只在临时目录验证。旧元信息、素材保真及局部交付规则不得回退。

## 设计

- `wxmeta.fingerprint` 保持前三个参数兼容，追加 `options` 与 `asset_hashes`；实际主题/标题/输出选项及本地资产内容参加指纹，渲染代码哈希覆盖新的 `wxbuild.py`。
- 新 `wxbuild.py` 集中管理 schema 2 清单、每个实际产物 SHA256、输出路径安全、版本校验及快照。`lint_artifacts` 委托共享实现，避免生成器与检查器各算一套输入。
- 清单记录有效渲染选项。校验按实际选项计算，同时检查当前源稿、主题、资产和清单声明的所有文件。丢失/篡改/清单结构损坏为 high；旧清单无法完整校验时明确提示，不冒充完整通过。
- 快照保存源稿、全部声明产物、输出目录内引用的本地图片和封面。快照不可原地覆盖；回退先验证所有摘要与路径，再恢复原路径源稿及相对输出资产，并清理上一版声明但本版没有的输出。缺失/目录逃逸资产不能生成完整快照。回退不恢复渲染脚本或全局主题配置，变更后仍须重新渲染。
- 写作检查区分“没有传卡片”与“明确传入但解析失败”；保留数字的符号与完整单位，规范等价小数；按列名保留空字段；围栏按符号/长度闭合；先清理大纲标题标记再读取正文，质量启发式不把短判断句一律判死。
- 文档快速开始双 strict、最终生成后双检查，按任务分支限定自检；实际图片文字、权限和微信粘贴仍需人工核验。

## 验收

每个问题先观察真实 CLI 失败，再修复。原 92 个测试与新增边界测试全跑；独立只读复核后继续处理确认问题；最终用临时目录跑主题覆盖、配图变更、快照/回退、双闸门以及局部渲染闭环。报告实际通过数量和未验证范围，不声称消除一切未知缺陷。
