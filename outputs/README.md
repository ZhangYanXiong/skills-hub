# 作品与交付文件

这里放已经生成的内容，按技能和日期主题寻找，不放skill源码或测试工作区。

- [文章视频作品](article-video/README.md)：MP4、封面、原文、旁白、分镜、音频、字幕和构建回执。
- [公众号作品](wechat-mp/README.md)：历史演示、正式验收、排版、配图与发布工作台。

## 命名与保存

正式项目采用 `outputs/<skill>/YYYY-MM-DD-主题/`。每个项目保留自己的源文件、素材和交付记录，内部相对路径不拆散。额外截图与审阅摘要可以放项目review/，但不要改动程序约定的video.mp4、audio/、build.json等位置。

导航说明随仓库保存；新作品默认gitignore，视频本机生成，不保证克隆仓库就存在。原有六组公众号演示明确保留，其他机器需要本地生成新作品。添加例外时先核实隐私、内容授权和体积，不能连带提交密钥、收费授权凭据或临时缓存。

历史作品中包含原生成时间与旧绝对源稿路径。移动目录不等于重新制作或新验收；旧回执保持原样，新制作需按当前skill完整检查。
