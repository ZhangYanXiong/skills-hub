# wechat-mp 回归测试

从 skills-hub 根目录运行：

```bash
python3 -I -B -m unittest discover -s skills/wechat-mp/tests -v
```

只依赖 Python 标准库。测试使用临时目录，不修改 `outputs/wechat-mp`，不上传素材，不访问公众号，不安装依赖。

## 覆盖范围

- `check.py`：三项必填元信息、64/20/120 字边界、标题/摘要/封面/作者/标签的风险扫描、反引号不能屏蔽元信息、所有已知字段的多行标记（含注释与缩进变体）、CLI 覆盖及空覆盖、正文代码屏蔽、JSON 字段定位、strict 返回码和显式缺失 HTML。
- `ingest.py`：相同句首不同数据、长句尾部数据、超过 80 条素材、完整重复句、空格影响实体、同名同格式输入、扩展名和自然后缀碰撞、大小写与 Unicode 规范等价名称碰撞及汇总表来源定位。
- `lint.py`：素材卡编号重复 / D 卡缺出处 / 出处无行号；正文空引用、存疑卡进正文、观点卡引用、数字无出处（含「数字在 F 卡也算命中」的回归）；大纲支撑未挂编号、主论点过短与套话、缺缺口清单；不传 `--cards` 时的降级；`--out` 产物版本校验（新鲜通过、改源稿后拦截、body 被替换、缺指纹、目录不存在）；`--json` 结构与 `--strict` 返回码。
- `md2wx.py` 与交付流程：新嵌套目录和带空格路径、`--no-body`、`--check` 无写入、输入/主题错误不创建目录、保留源稿与已有文件、四套主题最终工作台正文一致、封面文件发现与末次刷新。
- 文档契约：不将他人观点换成亲历、不用改量级绕过授权、保留许可/署名/适用边界、精确值与近似值不互换、涉密内容必须人工复核；任务分支先于完整创作提问，局部请求不强制改稿或补全全部产物。

`test_policy.py` 与 `test_delivery.py` 中的路由/顺序检查是静态契约检查，只能防止已识别的危险指令或流程规则回归，不证明模型在压力下必然遵守。它们不属于完整 Agent 行为 benchmark，也不作法律裁定。

工作台是生成时的静态快照。封面在同目录生成后，需重新运行原稿的 `md2wx.py --sheet` 命令，再打开或刷新页面。

构建指纹包含代码、源稿、有效主题/标题/输出选项以及本地图片和封面内容。schema 2 清单对每项声明的产物保存完整 SHA256，丢失、替换、错误结构和不一致都会被诊断；显式主题覆盖使用实际渲染参数。`article.body.html` 保持纯净不带标记。

`test_build.py` 用真实 CLI 覆盖主题/标题/作者覆盖、每项产物丢失/篡改、清单结构、无 body 的局部交付、图片变化、完整源稿/图片/封面回退、历史不可覆盖、回退前完整校验及安全路径。还覆盖源稿与固定清单/输出的符号链接、硬链接和父目录别名碰撞，大小写改名及旧声明文件清理、资产索引遗漏、共享围栏、中文副词、`--publish` 参数缺失、损坏历史列表。测试资产用于字节完整性，不冒充 Pillow 或微信图片验收。

`test_lint.py` 额外覆盖复合单位/正负值/等价小数/中文数量、明确传入但无法解析的素材卡、重排表头空字段/类型矛盾/无出处 F 卡、围栏匹配、加粗主论点/短判断/标点套话/中文支撑编号。

交付前在最终渲染后运行 `lint.py <md> --out <产物目录> --strict` 和 `check.py <md> --html <正文片段> --strict`；按请求范围验收。完整快照保存源稿、实际产物、输出目录内本地图片和封面；回退恢复原源稿路径，覆盖当前声明资产并清理不再需要的声明文件，因此操作前需确认用户回退意图。仅用可信本地快照；不回退渲染代码或全局主题配置，旧格式快照需重新生成。

## 可重复的真实 CLI 验收

```bash
python3 -I -B skills/wechat-mp/tests/verify_delivery.py
```

验收驱动在临时目录执行完整交付、显式主题/标题覆盖、默认署名、三档封面检查、改稿/换图阻断、历史列表、源稿/配图/封面字节回退、双 strict、缺文件与风险标题阻断、局部无 body 交付及 stdin 快照回退。预期阻断的步骤返回 1，其余返回 0；全部符合预期才输出 `status: passed`。真实模拟材料不证明文章事实，PNG 头尺寸检查不等于完整图片解码。

## 未覆盖的范围

- 微信后台粘贴后的真实样式、图片上传、账号接口权限与发布。
- Pillow 封面、Office 文件解析、扫描 PDF OCR。
- 事实的真实性、引用的法律适用、授权文件有效性、人工复核结论。
- Agent 实际执行局部任务分支的行为、剪贴板效果和 Markdown 解析器的全部边界。
- 指纹和摘要检查只证明已声明的产物/资产与构建输入一致，不能证明事实、授权或专业内容正确；渲染代码（含 wxbuild）参与哈希，改代码未升版本号也会让旧产物失效。
- 不承诺识别所有中文口语省略、财务大写、分数或所有 Markdown 扩展；已支持的中文数量/复合单位和围栏边界由具体测试覆盖。
- 本轮验收包含独立代码复核及临时目录真实交付/主题覆盖/快照回退，不以既有测试全绿替代复核。

`--strict` 是确定性检查门槛，不是发布授权。人工确认误报不使脚本自动返回 0；必须保留复核记录，必要专业终审仍由负责人完成。
