# 公众号合规自查（技术/产品 · 职场/成长）

> **这是发布前提示，不是过审保证。** 命中本清单的词不等于必然违规，未命中也不等于一定安全。平台的规则解释权在平台，最终判断必须由人来做；涉及法务、医疗、金融、教育等专业领域时，必须转人工或法务复核。本清单中的平台规则细节随版本变化，标注「需人工核实」的项请在发布前到后台或官方文档确认。

配套文档：`writing-playbook.md`（写作方法论）、`SKILL.md`（整体工作流）。

---

## 0. 使用说明

**适用对象**：准备发布技术/产品、职场/成长类内容的公众号运营者，以及辅助撰写内容的 AI agent。

**用法**：agent 在文章定稿后按 §1 走一遍。先核对事实、来源、许可和适用条件，再用 §4 的写法改善表述；不确定时停下来交给人工判断，不自行删改核心事实，也不靠删关键词取得发布资格。

**复核记录**：每个高风险命中从「待复核」开始，由负责人记录命中字段、原文、证据、处理结论及复核人，转为以下状态之一：

- **确认误报**：负责人结合语境与证据确认不适用该风险规则，并保留判断依据。
- **完成修订**：事实及使用权限已确认，修订后重新扫描；专业题材仍需人工/法务终审。
- **拒绝发布**：权限、证据或必要资质不能满足要求，相关内容不进入可发布定稿。

只有 **0 个未解决高风险** 且必要人工终审完成，才能交付为可发布稿。`check.py --strict` 只执行确定性检查，不能读取或代替人工复核记录；扫描通过不等于允许发布。

**三条原则**：

1. **合规优先于传播**：标题党带来的打开率，抵不上一次违规扣分。删文、限流、封禁功能的代价远大于一篇文章的流量。
2. **事实优先于话术**：一个无法举证的结论，无论怎么改写都仍有风险；先确认事实，再谈表述。
3. **不自行编造规则**：本清单没有覆盖的情况，写「需人工核实」，不要编造平台条款。

## 1. 发布前 5 步自查流程

1. **极限词扫描**：按 §2 逐类过标题、摘要、正文首屏、封面图文字。（封面图上的字同样受广告法约束，常被忽略。）
2. **诱导弹窗扫描**：按 §3.1 检查是否有索取分享/点赞/关注动作换取利益的话术。
3. **事实核对**：所有数字、结论、引用是否有出处；是否出现「据权威机构」这类无具体来源的表述。
4. **外链与转载检查**：按 §5 确认正文链接来源、图片版权、转载授权状态。
5. **人工终审**：检查是否触及 §3.4 特殊行业、§3.5 技术类高风险内容；命中即转人工/法务。

## 2. 广告法极限词清单

> 说明：《广告法》第九条对「国家级」「最高级」「最佳」等绝对化用语有明确禁止（原文与最新修订以官方公布为准）。市场监管总局已发布《广告绝对化用语执法指南》，明确绝对化用语并非一律违法、需结合语境判断——但**平台审核通常严于执法尺度**，商业推广类内容建议一律规避。以下为高风险词表，按类别分组。

### 2.1 绝对化用语（程度最高级）

| 类别 | 高风险词条 |
| --- | --- |
| 最字系 | 最好、最佳、最优、最强、最先进、最先进科学、最新技术、最高级、最高档、最高端、最低价、最便宜、最流行、最受欢迎、最时尚、最舒适、最符合、最赚、最具、最受欢迎品牌、最新鲜、最先进设备 |
| 顶级系 | 国家级、顶级、顶尖、尖端、巅峰、至尊、极品、极佳、极致、绝无仅有、无与伦比、独一无二、史无前例、前无古人、空前绝后 |
| 唯一系 | 唯一、唯一授权、独家、独家代理、独家首创、首家、首创、首个、冠军、之王、王者、王牌、掌门人、至尊品牌 |
| 领先系 | 领先、领导者、领袖品牌、领导品牌、创领品牌、第一品牌、金牌、名牌、一流、超一流、世界领先、国内领先、行业领先、遥遥领先 |

**替代写法**：把形容词换成可验证的事实。
- ❌「业界最强的限流方案」→ ✅「我们用它扛住了 8000 QPS 的尖峰」
- ❌「最先进的技术架构」→ ✅「改成事件驱动后，峰值延迟稳定在 120ms 以内」
- ❌「行业领先的团队」→ ✅「团队 6 人，负责 3 条业务线」

### 2.2 时间/范围绝对化

| 类别 | 高风险词条 |
| --- | --- |
| 时间 | 永久、终身、永远、一辈子、一劳永逸、永久有效、终身免费、终身保修、随时、立刻、马上见效、立竿见影、一次解决 |
| 覆盖 | 全国、全球、全网、全网最低、全网首发、全国首家、全网独家、覆盖全行业、全领域、全场景、万物皆可、万能、包罗万象 |
| 程度 | 100%、百分百、绝对、彻底、完全、毫无、零风险、零门槛、零成本、无副作用、无任何风险、绝对安全、绝对可靠、彻底解决 |

**注意**：「永久有效」「终身免费」这类承诺，即使当期真的免费，也构成对未来的承诺，一旦停止就是虚假宣传。改为写清适用期限与服务条款。

### 2.3 权威性表述

| 类别 | 高风险词条 |
| --- | --- |
| 国家机关关联 | 国家级、国家认证、国家推荐、官方指定、官方认证、政府指定（无授权文件即为虚假宣传） |
| 机构借势 | 央视推荐、央视上榜品牌、诺贝尔奖级、院士推荐、专家一致推荐、权威认证、权威机构认证、国际认证（未注明具体机构与编号的均为风险） |
| 身份伪造 | 权威专家、资深专家团队、行业泰斗、大师手笔、国家一级、享受国家津贴（未注明真实身份与出处即为风险） |
| 数据来源 | 据权威机构统计、大数据显示、调查表明（无来源即风险，尤其是无具体机构名与年份） |

**替代写法**：给具体来源、具体机构、具体编号、具体年份；给不出就删掉这个权威背书。

### 2.4 虚假承诺

| 类别 | 高风险词条 |
| --- | --- |
| 效果保证 | 保证有效、包治、根治、治愈、药到病除、治愈率、有效率、无副作用、彻底康复（医疗健康内容严禁） |
| 结果保证 | 保过、包过、包就业、保 offer、保录取、保过线、保证学会、保证涨粉、保证变现、保证回本 |
| 收益保证 | 稳赚、稳赚不赔、保本保收益、躺赚、暴富、月入十万、日赚、零投入高回报、无风险套利 |
| 服务保证 | 无条件退款（需与真实条款一致）、终身质保、永久售后、无限期支持 |

**注意**：技术/职场内容里最容易踩的是「保 offer」「包就业」「保证涨薪」「学完就能年薪 XX 万」。这类承诺既涉广告法，也涉教育/招聘类违规，见到即改。

### 2.5 价格类

| 类别 | 高风险词条 |
| --- | --- |
| 比较型价格 | 最低价、全网最低、史上最低、比 X 便宜、全网比价最低、折扣最低 |
| 虚假促销 | 原价 XX 现价 XX（无真实成交记录即为虚构原价）、限时秒杀（期限不真实）、清仓价、跳楼价、血亏、亏本、成本价 |
| 免费诱导 | 免费领取、0 元购、免费送、免费试用（未写清条件与期限） |

**替代写法**：写清价格、生效时间、适用范围与限制条件；促销价需有真实原价成交依据。

## 3. 公众号常见违规类型

平台规则依据以《微信公众平台运营规范》《微信外部链接内容管理规范》等官方文档为准；处罚尺度（删文、限制功能、限流、封号）随违规类型与次数变化，**具体处罚标准需人工核实**。

### 3.1 诱导关注 / 诱导分享 / 诱导点赞

**判定要点**：是否以「利益」换取用户的具体行为（关注、分享到朋友圈/群、点赞、在看、留言）。

| 违规话术示例 | 问题 |
| --- | --- |
| 转发到朋友圈并截图，后台回复「资料」领取完整版 | 以资料换取分享 |
| 集满 30 个赞解锁下一章 | 以内容解锁换取点赞 |
| 关注本号后回复关键词领 PDF | 以资料换取关注（视平台判定，属诱导关注高发区） |
| 分享到 3 个群可进内部群 | 诱导分享 + 私域导流 |
| 点赞 + 在看，抽 3 位送书 | 以抽奖换取互动 |
| 不转发就看不到后续 | 强制分享 |
| 助力/砍价/拼团类活动页 | 平台对助力、砍价类诱导有专项限制 |

**合规替代**：资料直接放在正文或站内文章中，读者无需任何动作即可取用；如需引导关注，只陈述「关注后会更新什么」，不给利益交换。参见 `writing-playbook.md` §5。

### 3.2 虚假信息与标题党

- 编造、散布谣言，尤其是事故、灾情、政策、企业重大事项类信息。
- 标题与正文严重不符（标题承诺「3 个方法」，正文只给 1 个）。
- 虚构亲身经历、伪造对话、伪造聊天记录截图。
- 使用「紧急通知」「刚刚」「内部消息」等无来源的紧迫性表述。
- AI 生成内容冒充真实照片/真实人物言论；技术类内容中伪造数据、伪造实验结论。
- 依据：《网络信息内容生态治理规定》等对虚假信息、标题党有明确规制（具体条款需人工核实）。

### 3.3 未经授权转载与版权侵权

- 转载他人原创文章未获授权，或未按授权范围修改原意。
- 未标来源、未保留作者署名。
- 使用他人图片、图表、代码仓库内容未遵守许可证（MIT/Apache 等许可仍需保留版权声明；GPL 内容引用需注意传染性条款）。
- 翻译外文文章/论文未获授权。
- 「洗稿」：换词改写他人文章结构，仍可能构成侵权。

**合规替代**：自己重画图表并注明数据来源；引用代码给仓库地址与许可证；转载走白名单（见 §5）。

### 3.4 特殊行业表述限制

**医疗健康**
- 禁止表示功效、治愈率、有效率；禁止「根治」「药到病除」「无副作用」。
- 非医疗机构、非执业医师不得提供诊疗建议；内容与就医建议相关时必须提示「不能替代专业诊断，请就医」。
- 不得使用患者案例作疗效证明（除非有完整授权且不涉及疗效承诺）。
- 涉及药品、医疗器械、保健食品的推广另有专门规定，**需人工/法务核实**。

**金融理财**
- 禁止承诺收益、保本保息、稳赚不赔；投资类内容需提示风险。
- 荐股、荐基、代客理财需相应资质；无资质不得从事证券投资咨询。
- 虚拟货币交易、炒币、挖矿相关内容属高风险区（监管明确禁止相关营销宣传，**需人工核实**）。
- 贷款、信用卡代还、征信修复类内容为高危广告方向，建议直接回避。

**教育培训**
- 禁止对升学、通过考试、获得学位学历/合格证书、培训效果作出明示或暗示的保证性承诺。
- 禁止利用科研单位、学术机构、教育机构、行业协会、专业人士、受益者的名义或形象作推荐证明。
- 「保过」「包上岸」「押题命中率」均属高风险。

**招聘求职**
- 禁止「付费内推」「保 offer」「简历包过」，此类话术兼具虚假承诺与求职诈骗嫌疑。
- 招聘信息需写清主体、岗位、薪资区间与工作地点；不得以招聘为名收集简历转售。

### 3.5 技术/产品垂类特有风险

这一节是本 skill 的重点：技术类文章很容易在「技术分享」的外衣下踩到法律红线。

| 高风险内容 | 风险点 | 处理建议 |
| --- | --- | --- |
| 破解、激活、去除授权校验 | 《网络安全法》第二十七条禁止提供侵入、干扰网络正常功能或窃取数据的程序工具；可能触及《刑法》第二百八十五条、第二百八十六条 | 不写原理、不给工具、不贴代码 |
| 未授权渗透测试、漏洞利用（含 0day） | 非法侵入计算机信息系统；未获授权即属违法 | 只写已公开、已修复的漏洞与防御侧经验；写清「已获授权」 |
| 爬虫抓取含个人信息的数据 | 《个人信息保护法》《数据安全法》；爬取简历、手机号、社交账号信息高风险 | 只讲公开数据与合规边界；不提供可直接运行的抓取代码 |
| 数据买卖、数据接口倒卖、脱敏数据再识别 | 侵犯公民个人信息罪（《刑法》第二百五十三条之一） | 不承接此类内容；不写「数据从哪来」的灰色渠道 |
| AI 换脸、声音克隆、伪造身份 | 侵犯肖像权、名誉权、个人信息权；易被用于诈骗 | 只讲合规用途与授权流程；须按《互联网信息服务深度合成管理规定》做显著标识（生成内容标识的具体要求需人工核实） |
| 绕过平台风控、批量注册、养号、刷量 | 平台运营规范明令禁止；可能构成不正当竞争 | 不写实操步骤 |
| 泄露公司内部代码、配置、架构、业务数据 | 违反保密义务与竞业协议；涉商业秘密侵权 | 先确认公开权限；授权或保密义务不明时暂停并转负责人审核，不能仅靠脱敏或抽象化使用 |
| 涉密单位、政务系统、军工相关技术细节 | 可能触及《保守国家秘密法》 | 一律不写，转人工判断 |
| 地图、国界线示意图 | 《地图管理条例》：不得漏绘、错绘国界线与重要岛屿；出版需审图号 | 用有审图号的合规地图图片，或直接不用地图 |
| 国旗、国徽、领导人形象用于商业推广 | 《国旗法》《国徽法》禁止用于商业广告 | 商业内容中不使用 |

## 4. 敏感表述与替代写法对照表

下表只是事实、来源与使用权限已确认后的表述参考，不是补造证据的模板。示例中的数据、认证、患者或读者反馈都必须有真实依据，不能为了套模板编写。涉及专业领域、保密义务或授权不明时先转人工；改写或脱敏不能解除保密义务。无法确认核心事实时暂停，是否排除相关内容由负责人确认，不自行删改事实后放行。

| ❌ 高风险表述 | 风险类型 | ✅ 替代表述 |
| --- | --- | --- |
| 行业第一 / 排名第一 / NO.1 | 绝对化用语 | 「在我们测过的 5 个方案里，这个方案的吞吐最高」 |
| 全网最低价 / 史上最便宜 | 价格绝对化 | 「当前定价 X 元，活动期至 12 月 31 日」 |
| 国家级认证 / 国家认可 | 权威性伪造 | 「通过了 XX 机构的 XX 认证（编号 XXX）」 |
| 100% 有效 / 零风险 | 虚假承诺 | 「在 XX 场景下的验证结果是 X；已知限制是 Y」 |
| 保证涨薪 / 保 offer / 包就业 | 结果承诺（教育/招聘高风险） | 「这套准备方法帮 3 位读者拿到了 offer（个人经历，不保证结果）」 |
| 稳赚不赔 / 保本保收益 | 金融虚假承诺 | 「以下是我的个人操作记录，不构成投资建议，市场有风险」 |
| 根治 / 治愈 / 药到病除 | 医疗疗效承诺 | 「部分使用者的反馈是 X；具体方案请遵医嘱」 |
| 万能方案 / 包治百病的技术架构 | 范围绝对化 | 「这个架构适合日均百万级请求的场景，不适合 XX」 |
| 永久免费 / 终身有效 | 时间绝对化 | 「当前版本免费，后续可能调整，以公告为准」 |
| 据权威机构统计 / 大数据显示（无来源） | 来源伪造 | 「据 XX 机构 2024 年发布的《XX 报告》第 X 页」 |
| 内部消息 / 独家爆料（无核实） | 虚假信息 | 「据 XX 官方 X 月 X 日公告」或直接删除 |
| 不转不是中国人 / 不分享就错过 | 诱导分享 + 道德绑架 | 删除，改为陈述内容价值 |
| 关注后回复「资料」领取 | 诱导关注 | 资料链接直接放在正文中 |
| 集赞 30 个解锁全文 | 诱导点赞 | 删除，全文直接放出 |

## 5. 外链与转载规则

> 微信的链接与版权策略迭代频繁，以下为通用结论；具体可配置项与限制**以公众号后台实际能力和官方公告为准，发布前需人工核实**。

### 5.1 正文外链

| 场景 | 规则要点 |
| --- | --- |
| 正文超链接 | 编辑器中的「超链接」主要支持指向公众号图文（含他人文章）、小程序、视频号等内容；**不能直接插入任意外部域名 URL**，强行粘贴外部链接通常不能成为可点击超链接 |
| 「阅读原文」 | 可配置站外链接，但能否配置、可配置的域名范围与账号认证状态相关，**需人工核实**；部分域名（含被平台判定为营销、诱导、竞品或安全风险的域名）会被拦截 |
| 短链、二维码导流 | 正文二维码/短链引导添加个人微信、导流站外群，属高频违规场景；需说明目的且不得以利益诱导 |
| 营销外链 | 《微信外部链接内容管理规范》对诱导分享、诱导关注型外链有专门限制，含助力、砍价、抽奖类页面 |
| 技术内容中的链接 | 引用 GitHub、官方文档、MDN 等通常可写成纯文本链接供复制；如需可点击，建议改为「搜索关键词」或站内成文后再引用 |

**实操建议**：正文里需要读者访问的外部资源，写成「可复制的纯文本地址 + 资源名称」，并在文末统一列出；不要指望正文外链能点开。

### 5.2 转载他人文章

- **必须获得授权**：通过公众号后台的「白名单/转载授权」机制获取授权（原创文章作者可授权单篇或长期转载，可设置是否允许修改、是否显示转载来源）。具体选项名称以后台为准。
- **保留署名与来源**：标明原作者、原公众号、原文链接（或说明来源）。
- **按授权范围修改**：授权不允许修改时，只能原文转载；允许修改时也不得改变原意、不得断章取义。
- **不得二次转授权**：未获授权的转载不能再授权给第三方。
- **转载后仍要履行本清单**：原作者文章里的极限词，你转载了同样要承担责任。

### 5.3 被转载与自己开白

- 自己的原创文章被他人申请转载时，可决定是否开白、是否允许修改；**建议保留「显示转载来源」**，便于溯源。
- 发现未授权转载：可先沟通补授权；沟通无效时，通过公众号后台的侵权投诉渠道处理，保留原文链接与发布时间截图作为证据。

### 5.4 图片、代码与数据

- 图片：使用有授权的图库、自制图或开源许可图；使用他人截图（含微信聊天、后台界面）需脱敏并确认不侵犯他人隐私与商业秘密。
- 代码：引用开源代码需遵守许可证（保留版权声明）；从公司项目复制代码前确认已脱敏且不涉密。
- 数据：引用第三方数据必须给出处；不得使用未授权获取的数据集。

## 7. 不确定时怎么办

1. **不确定某个词是否违规**：先按 §4 改写为可举证的事实表述——大多数风险可以用「给具体证据」化解。
2. **不确定平台某项规则**：标注「需人工核实」，去公众号后台的规则中心或官方公告确认，不要凭记忆写规则。
3. **不确定是否构成侵权**：假设构成，改用自制内容或取得授权。
4. **涉及医疗、金融、教育、招聘、法律、涉密内容**：一律转人工/法务，agent 不自行放行。
5. **拿不准就不发**：一篇待发的文章，成本远小于一次违规处罚。
