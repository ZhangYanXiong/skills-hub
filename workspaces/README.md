# 临时工作区

这里放制作中间件、调试实验和技能行为评估，不代表已经完成或通过验收的作品。

当前本机任务：

- `article-video/iteration-1/`：第一轮技能行为样本、流程基线与检查证据。
- `article-video/reviews/iteration-1.html`：官方skill-creator生成的离线行为审阅页面。
- `repository-layout/`：2026-11-12目录迁移映射、迁移前SHA-256清单和检查结果。

除本README外，工作区默认gitignore；其他机器不会自动获得这些本机实验文件。不要把workspace直接当成交付目录，也不要因是临时目录就擅自删除用户已有内容。

已生成作品去[outputs](../outputs/README.md)，可长期维护的实现去[skills](../skills/README.md)，设计与正式验收记录去[docs](../docs/README.md)。
